# AI Candidate Screening Platform

An AI-powered interview system that evaluates candidates through resume-aware technical interviews using Retrieval-Augmented Generation (RAG), Gemini, ChromaDB, FastAPI, and React.

## Demo

https://github.com/user-attachments/assets/9552f84c-7be4-4e3b-bbf9-8778034161ab

**Duration:** 1 minute 40 seconds

The demo showcases:

* Resume parsing using Gemini
* RAG-powered question generation
* Dynamic interview workflow
* AI answer evaluation and scoring
* Detailed assessment reports
* Overall candidate performance summary

## Tech Stack

### Backend

* FastAPI
* SQLAlchemy
* ChromaDB
* Google Gemini API
* PyMuPDF

### Frontend

* React
* Vite
* Axios

### AI Components

* Resume Parsing
* Retrieval-Augmented Generation (RAG)
* Technical Question Generation
* Answer Evaluation
* Candidate Assessment Summary
